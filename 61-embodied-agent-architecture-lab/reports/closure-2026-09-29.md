The final local command is `scripts/quality-gate.ps1 -RequireFinal`. It checks the 64 development cases, Python tests, handoff scope, web gate, persisted locked evaluation and promoted ROS campaign. The raw ROS bags and run records remain local/Git-ignored; tracked reports give their bounded results. The data-only handoff contains no runtime code, credentials or private bags.

Production-hardening work is outside this simulation-lab closure: enforced full-graph SROS2, exact all-message ROS replay, dynamic-obstacle collision validation, broader live fault injection and arm-stop latency distribution. These limits must travel with any release or demo.
